# Proyecto2_SIM
Este proyecto consiste en la simulacion de un cajero automatico desarrollado en Java utilizando programacion estructurada. El sistema permite al usuario realizar operaciones bancarias basicas desde la consola, incluyendo consultas de saldo, depositos, retiros y visualizacion de estadisticas de uso.
---------Funcionalidades-------
-Consultar saldo disponible.
-Depositar dinero en la cuenta.
-Retirar dinero validando fondos suficientes.
-Generar un numero de folio aleatorio para cada transaccion.
-Mostrar estadisticas de depositos y retiros realizados.
-Calcular el saldo final de la cuenta.
------Requisitos-------

Para ejecutar el programa es necesario tener instalado:

Java JDK 8 o superior.
Un editor o IDE como NetBeans, IntelliJ IDEA o Eclipse (opcional).

------Descarga del Proyecto-------
Metodo 1: Descargar ZIP
Ingrese al repositorio de GitHub.
Presione el boton Code.
Seleccione Download ZIP.
Extraiga los archivos en una carpeta de su computadora.

------Metodo 2: Clonar el repositorio------

Abra una terminal y ejecute:

git clone URL_DEL_REPOSITORIO

Ingrese a la carpeta del proyecto:

cd proyecto_sim

-------Como Ejecutar el Programa-------
Desde NetBeans o cualquier IDE
Abra el IDE.
Seleccione Abrir Proyecto.
Busque la carpeta del proyecto descargado.
Ejecute la clase Proyecto_sim.java.


--------Desde la Terminal--------

Compile el programa:

javac Proyecto_sim.java

Ejecute el programa:

java Proyecto_sim
